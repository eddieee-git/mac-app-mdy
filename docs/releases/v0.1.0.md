Mdy의 첫 버전이에요. Finder에서 `.md` 파일을 더블클릭하면 원본과 다듬어진 미리보기를 나란히 보여 주고, 어느 쪽에서든 고칠 수 있어요.

## 설치

- 아래 **Mdy-0.1.0.dmg**를 내려받아 Mdy를 응용 프로그램 폴더로 끌어다 놓으세요. 처음 열 때 경고가 나오면 **완료**를 누른 뒤 시스템 설정 → 개인정보 보호 및 보안 맨 아래의 **그래도 열기**를 누르세요(macOS 14는 오른쪽 클릭 → 열기).
- `.md` 파일을 더블클릭했는데 다른 앱이 열리면, Finder에서 ⌘I → **다음으로 열기**에서 Mdy를 고르고 **모두 변경**을 누르세요.

## 새 기능

- **원본과 미리보기를 나란히**: 툴바 비율 버튼(1:3 · 1:1 · 3:1)이나 가운데 구분선으로 폭을 바꾸고, 한쪽을 접을 수 있어요.
- **양쪽이 서로 따라가요**: 한쪽에서 고른 곳이 다른 쪽에 표시되고, 스크롤도 함께 움직여요.
- **미리보기에서 바로 고치기**: 미리보기를 두 번 클릭하면 그 블록이 마크다운 입력 칸으로 바뀌어요.
- **편하게 쓰기**: 문법 색칠, 서식 단축키(⌘B ⌘I ⌘K…), 목록·표 자동 이어쓰기, 괄호 짝 맞추기, 제목 접기, 줄 번호, 집중 모드.
- **붙여 넣기와 복사**: 웹·구글 문서·워드의 서식은 마크다운으로, 엑셀 칸은 표로. 미리보기에서 복사하면 메일·슬랙에 서식째 붙어요.
- **여러 문서**: 폴더 사이드바, 빠른 열기(⇧⌘O), 폴더 전체 검색(⇧⌘F), 문서 간 링크, 템플릿, 시작 창.
- **GitHub 스타일 문법**: 표, 체크리스트, 각주, 알림, 코드 색칠, `[TOC]`, 수식(KaTeX), 다이어그램(Mermaid). 수식과 다이어그램도 인터넷 없이 그려요.
- **내보내기**: HTML, PDF, Word, RTF, 프린트. Finder에서 스페이스 바로 훑어보기.
- **바뀐 줄 표시**: git 저장소의 문서는 마지막 커밋과 비교해서 바뀐 줄을 표시해요.

## 보안

- 미리보기는 문서 안의 스크립트를 실행하지 않아요(콘텐츠 보안 정책).
- 실행 파일을 가리키는 링크는 열지 않고, 다른 앱을 여는 주소는 먼저 물어봐요.
- 설정 → 미리보기 → **외부 이미지 막기**로 받은 문서를 열었다는 사실이 알려지지 않게 할 수 있어요.

## 알려진 제한

- macOS 14 이상이 필요해요(Apple 실리콘·Intel).
- Apple 개발자 서명이 없어서 dmg로 처음 열 때 경고가 나와요.
- Word로 내보내면 다이어그램 그림이 빠지고 수식은 TeX 글자로 바뀌어요.
- Finder 훑어보기에서는 수식과 다이어그램이 원문으로 보여요.

## English

The first version of Mdy. Double-click a `.md` file in Finder to see the source and a polished preview side by side, and edit on either side.

**Installing**
- Download **Mdy-0.1.0.dmg** below and drag Mdy into Applications. If macOS blocks the first launch, click **Done**, then **Open Anyway** at the bottom of System Settings → Privacy & Security (on macOS 14, right-click → Open).
- If double-clicking a `.md` file opens another app, press ⌘I on a `.md` file in Finder, choose Mdy under **Open with**, and click **Change All**.

**New**
- Source and preview side by side with ratio buttons (1:3 · 1:1 · 3:1), a draggable divider and collapsible panes.
- Both sides follow each other: selections are highlighted on the other side and scrolling stays in sync.
- Double-click the preview to edit that block in place.
- Syntax coloring, formatting shortcuts, list and table continuation, auto-closing brackets, folding headings, line numbers, focus mode.
- Formatted text from the web, Google Docs or Word pastes as Markdown, Excel cells as a table; copying from the preview keeps formatting.
- Folder sidebar, Open Quickly (⇧⌘O), search across a folder (⇧⌘F), links between documents, templates, start window.
- GitHub-style syntax including tables, footnotes, alerts, code coloring, `[TOC]`, math (KaTeX) and diagrams (Mermaid), rendered offline.
- Export to HTML, PDF, Word and RTF, print, and Quick Look in Finder.
- Changed lines since the last git commit.

**Security**
- Scripts inside documents never run in the preview (Content Security Policy).
- Links to executables aren't opened; Mdy asks before opening addresses that launch other apps.
- Settings → Preview → **Block remote images** keeps senders from knowing you opened a document.

**Known limitations**
- Requires macOS 14 or later (Apple silicon and Intel).
- Not signed by Apple, so macOS warns on first launch from the dmg.
- Word export leaves out diagram images and turns math into TeX text.
- Quick Look shows math and diagrams as source.
