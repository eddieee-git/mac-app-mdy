# Changelog

Details for each version are in [docs/releases](docs/releases) and [GitHub Releases](https://github.com/eddieee-git/mac-app-mdy/releases). 한국어: [CHANGELOG.md](CHANGELOG.md)

## 0.1.0 (2026-11-25)

- First public version
- Source and preview side by side, ratio buttons (1:3 · 1:1 · 3:1), position highlight and sync scrolling on both sides
- Double-click the preview to edit in place, tick checklists directly
- Syntax coloring, formatting shortcuts, list and table continuation, auto-closing brackets, folding headings, line numbers, focus mode
- Converts pasted formatted text and Excel cells, copies as rich text, pastes images
- Folder sidebar, Open Quickly, search across a folder, links between documents, templates, start window
- Tables, footnotes, alerts, code coloring, table of contents, math and diagrams (offline)
- Export to HTML, PDF, Word and RTF; Quick Look in Finder
- Changed lines since the last git commit, reloads files changed by other apps
- Scripts in the preview blocked, links to executables blocked, optional remote image blocking
- In-app updates, Korean and English
